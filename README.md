# Curvo v1.0.4
Vector curve / ribbon line maker (Java + XML, no external libraries).
Push to GitHub -> Actions tab -> "Build Curvo APK" -> download artifact `Curvo-debug-apk`.

v1.0.4: Trace PNG to vector, SVG export, freehand draw, variable width, multi-stop gradient,
smart layers (reorder, rename, lock, blend), symmetry, pattern fill, draw-on GIF/MP4, projects (.curvo).
